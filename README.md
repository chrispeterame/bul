# 找牛游戏

一款基于颜色区域和位置约束的逻辑解谜游戏。

## 游戏概述
玩家需要在n×n（默认5×5）的网格中，根据颜色分布和位置规则找出所有隐藏的牛。游戏结合了数独的位置约束和扫雷的标记系统，同时通过颜色区域增加了额外的推理维度。

## 游戏规则

### 网格与颜色
- 游戏棋盘是一个n×n的网格（默认5×5）
- 网格被随机划分为n个不同的颜色区域
- 每个颜色区域恰好包含**一头牛**

### 牛的位置约束
游戏中的牛遵循以下严格的位置规则：
1. **每行每列恰好一头牛**：类似国际象棋皇后的位置约束
2. **牛之间互不相邻**：任意两头牛不能在水平、垂直或对角线方向上相邻（即牛周围8个格子内不能有其他牛）
3. **每色一牛**：每个颜色区域恰好包含一头牛

### 玩家操作
1. **标记为牛**：点击格子标记为牛的位置
   - 如果标记正确：该位置会被标记为"cow"
   - 如果标记错误：该位置会被标记为"wrong"，并增加1次错误计数

2. **标记为非牛**：点击格子标记为"不是牛"（辅助标记）
   - 用于记录玩家确定没有牛的位置
   - 不影响游戏结果，仅作辅助提示

## 胜利与失败标准

### 胜利条件
当玩家同时满足以下条件时，游戏胜利：
1. 成功找到所有n头牛（默认5头）
2. 错误次数小于3次

### 失败条件
当玩家满足以下任一条件时，游戏失败：
1. 错误标记牛的位置达到3次
2. 主动放弃并揭示答案

## 游戏特色
- **唯一解保证**：每局游戏都保证有且只有一个有效解
- **随机生成**：每次游戏的颜色分布和牛的位置都是随机生成的
- **逻辑挑战**：结合了数独和扫雷的逻辑推理元素

## 核心逻辑实现

### 游戏生成机制
1. **牛位置生成**：使用回溯算法，确保每行每列一牛且牛之间不相邻
2. **颜色区域生成**：使用BFS算法，以牛的位置为起点向外扩展，将网格划分为n个连通区域
3. **唯一解验证**：通过回溯搜索验证生成的游戏是否只有唯一解

### 游戏状态管理
- `errors`：记录错误标记牛的次数（最大3次）
- `player_marks`：记录玩家的标记（牛、错误、未标记）
- `right_marks`：记录玩家的辅助标记（非牛）
- `game_over`：游戏是否结束
- `won`：游戏是否胜利

## 游戏提示
1. 利用颜色区域信息：每个颜色区域恰好有一头牛
2. 利用位置约束：牛之间不能相邻，每行每列只能有一头牛
3. 使用辅助标记：标记确定没有牛的位置，帮助排除干扰
4. 谨慎标记：错误标记会消耗宝贵的错误次数

## 技术实现
- 使用Python编写
- 核心算法：回溯法（牛位置生成、解验证）、BFS（颜色区域生成）
- 面向对象设计：使用`GameState`类管理游戏状态和逻辑

1. 安装依赖：`pip install -r requirements.txt`
2. 启动服务器：`python server.py`
